# jsbv.life — site briefing

Jack's personal data-experiments site. Static HTML, no build step.
Code on GitHub (JSBVcreations/jsbv.life, branch `main`) → deployed by Vercel (framework preset
"Other", no build command, root output). Same setup as maxfield.life. Every push to main goes live;
other branches get Vercel preview URLs.

## Where things live
- THIS folder (`~/Documents/03-Sites/jsbv.life`) = the live site, the git repo that gets pushed.
- `~/Documents/01-Projects/JSBV-Step-Song` = raw exports, drafts, backups for STEP//SONG.
  Raw Spotify JSON contains IP addresses → it never gets copied into this repo.

## Structure
```
index.html              landing page (project index)
step-song/index.html    STEP//SONG explorer (markup + CSS + JS in one file)
step-song/data/*.json   generated by scripts/build_step_song.py
scripts/                data builders
CNAME, .nojekyll        leftovers from a GitHub Pages plan; harmless, safe to delete
```

## Workflow
- Preview: `python3 -m http.server 8000` from this folder → http://localhost:8000
  (file:// won't work; the explorer fetch()es its data)
- Publish: commit + push to `main` (GitHub Desktop); Vercel deploys in ~1 minute.
- Refresh data after a new Spotify/Health export: see README.md.

## Design system (shared by landing + projects)
Dark CRT / synthwave, single theme. Tokens in each page's `:root`:
void #07060f · panel #0d0b1c · grid #1f1a3d · ink #dcd8ff · dim #8a84b8
cyan #3ff0ff = movement · magenta #ff3fb4 = listening · amber #ffb347 = stairs/elevation · lime #b6ff5c = trail
Fonts: Monoton (titles only), Chakra Petch (UI), JetBrains Mono (data).

## STEP//SONG data rules (scripts/build_step_song.py)
- Offline plays: Spotify logs them at sync time; real start = `offline_timestamp` (used when offline=true).
- EXTENDED_DAYS: days that ran past midnight count as one (2019-11-06 runs to 10:00 Nov 7, ~60-mile AT day).
- TRIPS: known-total trips for capture % (AT 2019: Jun 15–Nov 7, 2,192 mi, ~500,000 ft).
- Elevation gain = flights of stairs × 10 ft (Apple's flight definition).
- Movers/sitters need ≥3 h listened on ≥5 distinct days.
