# jsbv.life — site briefing

Jack's personal data-experiments site. Static HTML, no build step, hosted on GitHub Pages
(repo: JSBVcreations/jsbv.life, branch `main`, root). Custom domain via `CNAME`.

## Where things live
- THIS folder (`~/Documents/03-Sites/jsbv.life`) = the live site, the git repo that gets pushed.
- `~/Documents/01-Projects/JSBV-Step-Song` = raw exports, drafts, backups for STEP//SONG.
  Raw Spotify JSON contains IP addresses → it never gets copied into this repo.

## Structure
```
index.html              landing page (project index)
step-song/index.html    STEP//SONG explorer (markup + CSS + JS in one file)
step-song/data/*.json   generated by scripts/build_step_song.py
scripts/                data builders
CNAME, .nojekyll        GitHub Pages config
```

## Workflow
- Preview: `python3 -m http.server 8000` from this folder → http://localhost:8000
  (file:// won't work; the explorer fetch()es its data)
- Publish: commit + push to `main`; live in ~1 minute.
- Refresh data after a new Spotify/Health export: see README.md.

## Design system (shared by landing + projects)
Dark CRT / synthwave, single theme. Tokens in each page's `:root`:
void #07060f · panel #0d0b1c · grid #1f1a3d · ink #dcd8ff · dim #8a84b8
cyan #3ff0ff = movement · magenta #ff3fb4 = listening · amber #ffb347 = flights
Fonts: Monoton (titles only), Chakra Petch (UI), JetBrains Mono (data).

## Adding a new experiment
Make `/<slug>/index.html` with its own `data/`, reuse the tokens, add a card to `index.html`.
